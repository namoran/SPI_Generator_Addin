SPI Generator

An Excel add-in by Moran Rocks LLC. It transfers the line items from a PRP change order (RFC) into the SPI workbook open in Excel. Only the task quantity cells change; Excel recalculates the totals.

The add-in runs in the task pane in Excel. Open your SPI workbook, select the RFC workbook, and select Generate. The add-in reports every quantity it writes.

The web version of this tool is at namoran.github.io/SPI_Generator.
