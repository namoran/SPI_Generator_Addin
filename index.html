RFC Importer

An Excel add-in by Moran Rocks LLC. It imports the line items from a PRP change order (RFC) into the SPI workbook open in Excel. Only the task quantity cells change; Excel recalculates the totals.

The add-in runs in the task pane in Excel. Open your SPI workbook, choose RFC data from a file or from the RFC worksheet in the workbook itself, and select Import. The add-in reports every quantity it writes, and refuses to import the same RFC data a second time.

The web version of this tool is at namoran.github.io/SPI_Generator.
